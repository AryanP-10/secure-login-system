# Secure Login System

JWT based authentication system using Spring Security.

## Features

- User Registration
- User Login
- JWT Token Generation
- BCrypt Password Encryption
- Role Based Access
- Admin Dashboard
- Global Exception Handling
- Token Expiry

## APIs

POST /auth/register

POST /auth/login

GET /admin/dashboard

## Tech Stack

- Java 21
- Spring Boot
- Spring Security
- JWT
- MySQL
- JPA
- Maven
